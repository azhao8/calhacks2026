# Connecting the event scout to Melos

How the scout reaches Convex (CLAUDE.md §6.1, §8.2 Events). The Store README is `README.md`; this file is for the team.

## Build and deploy the actor

```bash
cd apify
npm ci
npm test
npm run build
apify login --token "$APIFY_TOKEN"
apify secrets add melosAnthropicKey "<Anthropic key>"   # once per machine; stored in ~/.apify, never in git
apify push
```

`.actor/actor.json` maps the secret to `MELOS_ANTHROPIC_API_KEY`. The actor uses it only when the run belongs to the owner's Apify account (`MELOS_OWNER_USER_ID`); anyone else running the published actor must pass their own `anthropicApiKey`.

Actor: `prolific_moccasin_3df~melos-event-scout` (ID `cFV7d32aE4FOWeJq5`). Convex reads the name from `APIFY_SCOUT_ACTOR` and falls back to that value.

## Daily schedule (about 6:00 AM PT)

Apify Console → Schedules → Create:

- Cron: `0 6 * * *`, timezone `America/Los_Angeles`.
- Action: run actor `melos-event-scout` with input `{}` (all sources, 14 days ahead), memory 1024 MB, timeout 3600 s.

## Webhook into Convex

Apify Console → the actor → Integrations → Webhook (or `POST /v2/webhooks`):

- Event types: `ACTOR.RUN.SUCCEEDED`, `ACTOR.RUN.FAILED`, `ACTOR.RUN.TIMED_OUT`, `ACTOR.RUN.ABORTED`.
- URL: `https://<deployment>.convex.site/apify/webhook` (dev: `https://elated-barracuda-447.convex.site/apify/webhook`).
- Headers template: `{"x-melos-webhook-secret": "<APIFY_WEBHOOK_SECRET>"}`, the same value as the Convex env var (generated by `scripts/push-secrets.sh`).
- Payload template: Apify's default (it carries `eventType` and `resource.id`, `resource.defaultDatasetId`).

The endpoint answers at once, records the run in `eventImports` (a repeated run ID is ignored), and the syncPool runs the import. "Find events now" on the admin page calls `internal.events.admin.findNow`, which starts a run the same webhook brings back.

## Convex environment variables this needs

`APIFY_TOKEN`, `APIFY_WEBHOOK_SECRET`, `VOYAGE_API_KEY`, and optionally `APIFY_SCOUT_ACTOR`.
